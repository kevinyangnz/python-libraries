# Matplotlib

Matplotlib is a library for creating static, animated and interactive visualizations in Python.

Key features of Matplotlib include:

- Creating plots (line plots, scatterplots, histograms, bar graphs etc)
- Customized styling
- Subplots (Multiple plots within specified grids)
- Integrated with NumPy and Pandas

# Seaborn

Seaborn is built on Matplotlib and is used for statistical data visualisation.

Key features of Seaborn include:

- Statistical plots (box plots, violin plots, pair plots etc)
- Simple syntax compared to Matplotlib
- Several built-in themes for aesthetics
